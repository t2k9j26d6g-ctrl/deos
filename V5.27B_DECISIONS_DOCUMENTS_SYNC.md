# DEOS V5.27B — Décisions + Documents

## Objectif
Ajouter la synchronisation multi-appareils des **Décisions** et des **Documents / comptes-rendus**, sans modifier les données existantes.

## Avant test connecté
Exécuter dans Supabase SQL Editor, dans cet ordre :
1. `supabase/migrations/010_v5_27b_decisions_hybrid.sql`
2. `supabase/migrations/011_v5_27b_documents_hybrid.sql`

Ensuite, dans DEOS > Paramètres, analyser puis activer séparément les pilotes Décisions et Documents.

## Sécurité
- désactivés par défaut ;
- soft-delete distant ;
- contrôle de version ;
- conflit détecté si local et distant ont changé depuis la dernière synchronisation ;
- aucune réinitialisation du localStorage.
